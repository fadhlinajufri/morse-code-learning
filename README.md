# morse-code-learning
CSC649 Assignment 1: Problem formulation, requirements, and specialized technology for a Morse code learning system.

## Overview
Morse code is one of the earliest telecommunication methods has become less commonly used today due to the prevalence of mobile communication technologies. (Sushmitha, S., Prasad, H. B., & Sapna, V. M., 2025). However, it remains useful in assistive technology. Every letter and number is built from only two signals which is a dot and a dash, so it suits people who can produce only a few distinct inputs. When it is combined with eye blinks, short blinks can represent dots and long blinks dashes, so all alphanumeric characters can be entered through blink duration alone (Pavithraa, 2026). Blinking is an useful channel because it often remains controllable even in the later stages of motor impairment.
