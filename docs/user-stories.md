## User Stories

1. As a learner with limited hand movement, I want the system to calibrate to my own eyes, so that my short and long blinks are detected correctly.
Acceptance criteria:
- After calibration, the system displays the threshold it set for the user and confirms it is ready.
- In a test of 10 short and 10 long blinks, at least 18 of 20 are classified correctly.
- (linked to FR3)

2. As a beginner, I want to see a few letters and their Morse patterns at a time, so that I am not overwhelmed and can memorise the code step by step.
Acceptance criteria:
- Each lesson shows no more than 3 characters, each with its dot-dash pattern.
- The user can move to the exercise only after finishing the lesson screen.
- (linked to FR4)

3. As a learner, I want immediate feedback on my blink exercises, so that I know whether I have really learned the code.
Acceptance criteria:
- After each attempt, the system shows correct or incorrect within 1 second.
- When an answer is wrong, the system shows the correct pattern next to what the user entered.
- (linked to FR5, FR6)
